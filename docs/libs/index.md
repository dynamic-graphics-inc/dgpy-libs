# Libraries

Every lib is published on PyPI under its own name, and `dgpylibs` installs the
lot.

| Library                          | What it does                                    | Install                  |
| -------------------------------- | ----------------------------------------------- | ------------------------ |
| [aiopen](aiopen/index.md)         | Async file IO                                   | `uv add aiopen`          |
| [asyncify](asyncify/index.md)     | Sync → async: run blocking code from async land | `uv add asyncify`        |
| [fmts](fmts/index.md)             | String transformation utilities                 | `uv add fmts`            |
| [funkify](funkify/index.md)       | Make modules callable                           | `uv add funkify`         |
| [h5](h5/index.md)                 | h5py utilities & CLI                            | `uv add h5`              |
| [jsonbourne](jsonbourne/index.md) | EZPZ JSON — secret-agent JSON objects           | `uv add jsonbourne`      |
| [lager](lager/index.md)           | EZ-PZ logging built on loguru                   | `uv add lager`           |
| [listless](listless/index.md)     | Generator & iterable utilities                  | `uv add listless`        |
| [requires](requires/index.md)     | Runtime imports & dependency utilities          | `uv add requires`        |
| [shellfish](shellfish/index.md)   | Shell & filesystem utilities                    | `uv add shellfish`       |
| [xtyping](xtyping/index.md)       | `typing` + `typing_extensions`                  | `uv add xtyping`         |
| [dgpytest](dgpytest/index.md)     | pytest plugin & fixtures                        | `uv add --dev dgpytest`  |
